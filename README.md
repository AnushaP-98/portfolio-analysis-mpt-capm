# Portfolio Analysis using MPT, CAPM & Bond Analysis

## Overview

This project applies core concepts from **Modern Portfolio Theory (MPT), CAPM, Price-Volume Analysis, and Fixed Income Analysis** to selected Indian financial securities.

The analysis uses daily market data for six selected stocks along with the **NIFTY 50** as the market benchmark. The workbook also includes analysis of selected government securities and a corporate NCD.

## Objectives

- Calculate daily returns, mean returns, standard deviation, and beta for selected stocks.
- Construct portfolios using different weighting approaches.
- Compare portfolio performance and risk.
- Analyze the relationship between stock price and trading volume.
- Calculate required rates of return using CAPM.
- Analyze selected government and corporate bonds using price, yield, coupon, volume, and maturity information.

## Stocks Analyzed

The portfolio includes:

- HCL Technologies
- ITC
- HDFC Bank
- Maruti Suzuki
- Reliance Industries
- Dr. Reddy's Laboratories

**Benchmark:** NIFTY 50

## Methodology

### 1. Modern Portfolio Theory

Three portfolio weighting approaches were analyzed:

- **Minimum Variance Portfolio** — focuses on minimizing portfolio risk.
- **Value-Weighted Portfolio** — weights stocks according to market capitalization.
- **Price-Weighted Portfolio** — weights stocks according to their share prices.

The analysis includes individual stock returns, volatility, beta, portfolio weights, and portfolio-level performance measures.

### 2. Price-Volume Analysis

Daily stock prices and trading volumes were analyzed over the study period to examine how changes in trading activity relate to stock price movements.

### 3. CAPM Analysis

The Capital Asset Pricing Model was used to estimate the required rate of return for each selected stock based on:

- Risk-free rate
- Stock beta
- Market return
- Market risk premium

### 4. Bond Analysis

Selected government securities and a corporate NCD were analyzed using:

- Issuer
- Last traded price
- Trading volume
- Yield to maturity
- Face value
- Coupon rate
- Remaining maturity
